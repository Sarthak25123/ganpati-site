# Maanache Ganpati Darshan Guide — Pune

A browser guide for walking Pune’s five honoured Ganpatis in ceremonial order: Kasba, Tambdi Jogeshwari, Guruji Talim, Tulshibaug, and Kesariwada.

**Live site:** https://sarthak25123.github.io/ganpati-site/

```bash
npm install
npm run dev
```

The site is published from the `main` branch with GitHub Pages (Actions).
